# 吹牛骰子

AstrBot QQ 官方群聊吹牛骰子插件，参考 `astrbot_plugin_official_TexasHoldem` 的房间、开始、发牌按钮和结算流程实现。

## 骰子查看方式

- 不使用私聊发送。
- 开始游戏后，每条游戏消息都会附带只对本人可见的“看骰”按钮。
- 按钮的 `data` 中包含自己的骰子；点击后内容只出现在本人输入框，请勿发送到群里。
- 该机制与 `astrbot_plugin_official_TexasHoldem` 的“查看手牌”按钮一致。

## 玩法规则

- 每名玩家默认 10 颗骰子，开始后由服务器掷骰，所有骰子隐藏。
- 开局随机抽取一名先手玩家，第一手只能由这名先手叫骰。
- 第一手之后不再轮圈：除当前叫骰者外，任意玩家都可以继续叫骰或开骰。
- 叫骰格式：`叫 4 3`，表示猜测全场至少有 3 个 4。
- 当前叫骰者不能连续叫骰，也不能开自己的叫骰。
- 开骰时开骰方指定双方各下注的筹码，双方下注总上限为 2000；被开的人可以发送 `加筹码 50` 在原本下注上追加双方筹码，达到上限后不能继续追加，开骰方不能拒绝。
- 当前行动者会看到“叫 / 开”按钮；开骰后由被开者点击“加筹码 / 揭晓”。
- 被开的人发送 `揭晓` 后展示全场骰子并结算。
- 若全场指定点数的实际数量 **大于等于** 叫数，则被开的人赢；否则开骰的人赢。
- 本插件不采用 1 点万能规则，1 只按 1 点计算。

## 命令

| 命令 | 说明 |
| --- | --- |
| `吹牛菜单` / `吹牛帮助` | 查看帮助和规则 |
| `吹牛创建` / `吹牛开局` | 创建房间，创建者成为房主 |
| `吹牛加入` / `吹牛报名` | 加入等待中的房间 |
| `吹牛退出` / `吹牛离开` | 开局前退出房间 |
| `吹牛开始` | 房主或管理员掷骰并开始游戏 |
| `吹牛看` / `吹牛状态` | 查看公开状态、当前行动者和双方筹码 |
| `吹牛看骰` / `我的骰子` | 显示只属于自己的看骰按钮 |
| `叫 4 3` | 叫骰，表示猜 3 个 4 |
| `开 100` | 开上家的骰，并指定双方各下注 100 筹码 |
| `加筹码 50` | 被开后在本局原下注上追加 50 筹码 |
| `揭晓` | 展示骰子并结算 |
| `吹牛结束` / `吹牛取消` | 房主或管理员结束房间 |

## 兼容写法

- `叫 3个4` 等价于 `叫 4 3`。
- `叫 4 3个` 等价于 `叫 4 3`。
- 开骰数量可以省略，默认下注 1 筹码。

## 筹码说明

默认情况下，每局每名玩家从 `starting_chips` 开始，开骰/加筹码不会立刻扣除，而是在 `揭晓` 时一次性结算：赢家 `+筹码`，输家 `-筹码`。因此双方都不能通过拒绝来避免下注。

## 与官方德州插件共用筹码

插件已提供可选适配器，可读写 `astrbot_plugin_official_TexasHoldem` 的 SQLite 筹码表：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `use_texas_holdem_chips` | `false` | 开启后与官方德州共用每日筹码 |
| `texas_holdem_plugin_name` | `astrbot_plugin_official_TexasHoldem` | 官方德州插件目录名 |
| `texas_chip_initial` | `600` | 官方德州插件每日初始筹码 |

开启后：

- 吹牛开始游戏时读取 `holdem_daily_chips` 中每名玩家的当天筹码；
- 吹牛揭晓结算时写入 `holdem_daily_chips` 和 `holdem_total_delta`。

数据文件位于：

```text
data/plugin_data/astrbot_plugin_official_TexasHoldem/texas_holdem.sqlite3
```
